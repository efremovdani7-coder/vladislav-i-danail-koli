# 🚗 АвтоНадеждност.бг — Система за анализ на надеждността на автомобилите

**Владислав и Данаил** · ASP.NET Core 8 MVC · Entity Framework Core + SQLite · SignalR · Bootstrap 5 (синя тема)

Сайт на български, в който собствениците споделят реалния си опит с автомобилите — дефекти, разходи за поддръжка и пробег.
От тези данни се изчислява **индекс на надеждност (1–100)** за всеки модел и **обща оценка за всяка марка**.

---

## ▶️ Как да стартирате сайта във Visual Studio Code

### 1. Инсталирайте (еднократно)
1. **.NET 8 SDK** — https://dotnet.microsoft.com/download/dotnet/8.0 (изберете „SDK“ за вашата система).
   Проверка в терминал: `dotnet --version` → трябва да започва с `8.`
2. **Visual Studio Code** — https://code.visualstudio.com
3. В VS Code: разширение **C# Dev Kit** (Microsoft). VS Code ще ви го предложи сам при отваряне на папката.

### 2. Отворете проекта
- **File → Open Folder…** и изберете папката на проекта (тази, в която е `CarReliability.csproj`).
- Ако сте го взели от GitHub: `git clone https://github.com/efremovdani7-coder/vladislav-i-danail-koli.git`

### 3. Стартирайте
**Вариант А — бутон F5:** натиснете **F5** (или *Run → Start Debugging*) и изберете „Стартирай сайта (F5)“. Браузърът се отваря сам.

**Вариант Б — терминал:** *Terminal → New Terminal* и напишете:
```bash
dotnet run
```
След това отворете **http://localhost:5000** в браузъра.

> **Първото стартиране** отнема 10–30 секунди: изтеглят се NuGet пакетите, създава се базата `avtonadejdnost.db`
> и се зарежда каталогът с ~1 100 модела и ~23 000 варианта на двигатели. Следващите стартирания са бързи.
> Спиране: **Ctrl+C** в терминала (или Shift+F5).

### 4. Вход като администратор
| Имейл | Парола |
|---|---|
| `admin@cars.bg` | `admin123` |

Сменете паролата в `appsettings.json` → `AdminAccount`, преди да публикувате сайта.

### Чисто начало
Изтрийте файла `avtonadejdnost.db` — при следващото стартиране базата се създава наново.

## ✅ Реализирани User Stories

| US | Описание | Къде в сайта |
|----|----------|--------------|
| US01 | Въвеждане на данни за автомобил — падащи менюта **Марка → Модел → Поколение → Година → Двигател → Скоростна кутия**, всяко показва само възможностите за избраното преди него. Ръчно се въвеждат само пробег, разходи, оценка и дефекти. | *Добави* |
| US02 | Справки по марка / модел / година / гориво, резултатите се обновяват без презареждане | *Справки* |
| US03 | Сравнение на 2–3 модела рамо до рамо + стари срещу нови коли (граница по година, по поколения и по десетилетия) | *Сравнение*, страница на модел |
| US04 | Графики (Chart.js): разходи спрямо година и пробег, кръгова диаграма на дефектите, оценка по години | страница на модел |
| US05 | Регистрация с уникален никнейм (3–20 символа); паролата се въвежда **два пъти** | *Регистрация* |
| US06 | Админ панел: редакция/изтриване на отзиви и коментари, блокиране/изтриване на потребители | *Админ* |
| US07 | Индекс на надеждност 1–100 за всеки модел (зелено 80–100, жълто 50–79, червено 1–49) | навсякъде |
| US08 | Превключвател тъмна/светла тема (запазва се в браузъра) | бутон 🌙 в менюто |
| US09 | Търсачка с подсказки за марки и модели (от 2 символа) | полето в менюто |
| US10 | Коментари и оценка 1–5 звезди (по един глас на потребител) | страница на модел |
| US11 | „Следи модел“ → известие в сайта (на живо) + имейл при нови данни | страница на модел, 🔔 |
| US12 | Вход с Google / Facebook (включва се с ключове в `appsettings.json`) | *Вход* |
| US13 | Чат в реално време между потребители (SignalR) | 💬 в менюто |
| US14 | Линкове към YouTube, Instagram, TikTok, Viber | футър |
| US15 | Адаптивен дизайн за телефон, таблет и компютър | навсякъде |
| US16 | Бутони за търсене на обяви в Mobile.bg, Cars.bg и OLX за избрания модел | страница на модел |

**Допълнително:**
- **Обща оценка за всяка марка** (а не една обща оценка за всички коли) — *Марки* и началната страница.
- **История на влизанията** — всяко влизане (успешно или неуспешно) се записва в базата с дата, IP, браузър и начин на вход.
  Администраторът може да филтрира, изтегля (CSV/Excel) и изтрива записите: *Админ → История на влизанията*.
  Всеки потребител вижда последните си влизания в *Моят профил*.

### Как се изчислява индексът на надеждност
| Фактор | Тегло |
|---|---|
| Средна оценка на собствениците (1–10) | 50% |
| Честота на дефектите (0 дефекта = 100, 5+ = 0) | 20% |
| Годишни разходи за поддръжка (0 € = 100, 3000 €+ = 0) | 15% |
| Звезди от потребителите (1–5) | 15% |

Логиката е в `Services/ReliabilityService.cs`.

## ⚙️ Настройки (`appsettings.json`)

**Вход с Google (US12):** създайте OAuth клиент в https://console.cloud.google.com → *APIs & Services → Credentials*,
добавете `http://localhost:5000/signin-google` като *Authorized redirect URI* и попълнете `Authentication:Google:ClientId` и `ClientSecret`.

**Вход с Facebook (US12):** създайте приложение в https://developers.facebook.com, добавете *Facebook Login*
с redirect `http://localhost:5000/signin-facebook` и попълнете `Authentication:Facebook:AppId` и `AppSecret`.

Бутоните за Google/Facebook се показват само когато ключовете са попълнени.

**Имейл известия (US11):** попълнете секцията `Email` (SMTP сървър, напр. Gmail с „App password“: `smtp.gmail.com`, порт `587`).
Без SMTP настройки известията в сайта работят, а имейлите само се записват в конзолата.

**Социални мрежи (US14):** линковете са във `Views/Shared/_Layout.cshtml` (футър) — заменете ги с вашите профили.

## 🗂 Източник на данните за автомобилите
Каталогът (марки, модели, поколения, двигатели, мощност, скоростни кутии, задвижване) е извлечен от публичната база
[automobile-models-and-specs](https://github.com/ilyasozkurt/automobile-models-and-specs) (данни от autoevolution.com, 10.2024),
филтриран до марките, разпространени в България, и преведен на български. Скриптът за преобразуване е `Data/Seed/build_catalog.py`.
