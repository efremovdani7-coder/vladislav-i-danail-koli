# 🚗 АвтоНадеждност.бг — Система за анализ на надеждността на автомобилите

**Владислав и Данаил** · ASP.NET Core 8 MVC · Entity Framework Core · PostgreSQL (облачна база) · SignalR · Bootstrap 5 (синя тема)

Сайт на български, в който собствениците споделят реалния си опит с автомобилите — дефекти, разходи за поддръжка и пробег.
От тези данни се изчислява **индекс на надеждност (1–100)** за всеки модел и **обща оценка за всяка марка**.

## ▶️ Как да стартирате сайта във Visual Studio Code

### 1. Инсталирайте (еднократно)
1. **.NET 8 SDK** — https://dotnet.microsoft.com/download/dotnet/8.0 (изберете „SDK“). Проверка: `dotnet --version` → `8.…`
2. **Visual Studio Code** — https://code.visualstudio.com и разширението **C# Dev Kit** (VS Code сам ще го предложи).

### 2. Отворете проекта
**File → Open Folder…** → папката с `CarReliability.csproj`
(или `git clone https://github.com/efremovdani7-coder/vladislav-i-danail-koli.git`).

### 3. Свържете облачната база данни (еднократно, вижте раздела по-долу)

Натиснете **F5** — или в терминал (*Terminal → New Terminal*): `dotnet run` и отворете **http://localhost:5000**.

## 🗄️ Къде се пазят регистрираните потребители

Всички данни (потребители, отзиви, коментари, съобщения, история на влизанията, каталог) са в **база данни PostgreSQL**:

| Таблица | Какво съдържа |
|---|---|
| `AspNetUsers` | регистрираните потребители: имейл, никнейм, хеширана парола (не самата парола), дата на регистрация, блокиране |
| `AspNetUserRoles` / `AspNetRoles` | кой е администратор и кой обикновен потребител |
| `AspNetUserLogins` | свързани профили от Google / Facebook |
| `LoginRecords` | всяко влизане (успешно и неуспешно) |
| `CarEntries`, `ModelComments`, `ModelRatings`, `ChatMessages`… | отзиви, коментари, звезди, съобщения |

Базата е **сървър в облака** (напр. безплатен Neon): данните се записват и четат в реално време,
и двамата виждате едни и същи потребители и отзиви от всеки компютър. Таблиците могат да се разглеждат в
**Neon → Tables / SQL Editor** или в сайта: *Админ → Потребители*.

Ако не е въведена връзка към PostgreSQL, сайтът автоматично използва резервен локален файл `avtonadejdnost.db` (SQLite)
и пише предупреждение в терминала и в *Админ → Каталог и тестови данни*.

### Облачна база данни (Neon PostgreSQL) — настройка
1. Регистрирайте се безплатно в **https://neon.tech** (може с Google или GitHub акаунт).
2. **Create project** → име `avtonadejdnost`, регион **Europe (Frankfurt)**, PostgreSQL 16 или по-нов.
3. В **Connection Details** копирайте низа за връзка — изглежда така:
   `postgresql://neondb_owner:ПАРОЛА@ep-xxxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`
4. В терминала на VS Code, в папката на проекта, изпълнете (с вашия низ в кавичките):
   ```bash
   dotnet user-secrets set "ConnectionStrings:PostgreSql" "postgresql://neondb_owner:ПАРОЛА@ep-xxxx.eu-central-1.aws.neon.tech/neondb?sslmode=require"
   ```
   Така паролата се пази на вашия компютър извън проекта и **не се качва в GitHub**.
   Другият член на екипа изпълнява същата команда със същия низ — и двамата работите с една база.
5. Стартирайте сайта. В терминала трябва да пише `База данни: PostgreSQL сървър (ep-xxxx…)`. Таблиците се създават сами.

Смяна обратно на локален файл: в `appsettings.json` → `"Database": { "Provider": "Sqlite" }`.

> ⚠️ Таблиците се създават при първо стартиране. Ако по-късно промените моделите в кода (добавите поле),
> изтрийте таблиците в Neon (*SQL Editor*: `DROP SCHEMA public CASCADE; CREATE SCHEMA public;`) и стартирайте отново.

## 🚘 Данни за автомобилите — от две публични бази

| Източник | Какво дава | Как се използва |
|---|---|---|
| **autoevolution.com** (публична база [automobile-models-and-specs](https://github.com/ilyasozkurt/automobile-models-and-specs), 10.2024) | 47 марки, ~1 100 модела, ~4 800 поколения, ~23 000 двигателя с кутии и задвижване, **размери** (дължина, ширина, височина, междуосие, клиренс, багажник, тегло) | вграден каталог (`Data/Seed/car-catalog.json`), зарежда се при първо стартиране |
| **FuelEconomy.gov** — официална база на Агенцията по околна среда на САЩ (EPA) | всички модели, продавани в САЩ от 1995 г.: двигател, кутия, задвижване, гориво по години; добавя и марки като Acura, Cadillac, Genesis, Lincoln, Rivian… | сайтът я изтегля сам от интернет (фонов импорт); ръчно: *Админ → Каталог и тестови данни → Обнови* |
| **NHTSA vPIC** — официална база на Министерството на транспорта на САЩ | разчитане на VIN номер → марка, модел, година, двигател | на формата *Добави* → „Попълни автоматично по VIN номер“ |

Версиите от EPA са отбелязани с „· САЩ“ в менютата. Скриптът, който подготвя каталога: `Data/Seed/build_catalog.py`.

## 🧪 Тестови данни
При първо стартиране се създават 8 тестови потребителя (никнейм „Тест_…“, парола `test123`) с ~130 примерни отзива
за популярни в България модели, коментари, звезди, съобщения и история на влизанията — за да се видят класациите,
графиките и сравнението. Тестовите отзиви са отбелязани с „[Тестови данни]“ и значка „тест“.
Изтриване/добавяне: *Админ → Каталог и тестови данни*. Изключване: `appsettings.json` → `"TestData": { "Seed": false }`.

### Индекс на надеждност
Оценка на собствениците 50% · честота на дефектите 20% · разходи за поддръжка 15% · звезди 15% (`Services/ReliabilityService.cs`).

## ⚙️ Други настройки (`appsettings.json`)
- **Google / Facebook вход:** попълнете `Authentication:Google` / `Authentication:Facebook` (redirect адреси `http://localhost:5000/signin-google` и `/signin-facebook`). По-добре също чрез `dotnet user-secrets set`.
- **Имейл известия:** секция `Email` (SMTP, напр. `smtp.gmail.com`, порт 587, „App password“).
- **Публични бази:** секция `PublicData` (`AutoImport: false` спира автоматичния импорт).
- **Социални мрежи:** линковете са във `Views/Shared/_Layout.cshtml`.
